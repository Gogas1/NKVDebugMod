# Another debug mod
## Features:

### Monster inspector

The Monster inspector allows you to select a monster to get some relevant information and change its states.
<br>
There's also a button to immediately inspect the monster in Unity Explorer. It doesn't automatically activate the UE overlay

### Time controller

The Time Controller allows you to pause or scale game time, as well as selectively advance it either by frames or by a fixed amount of time

### Save manager

The Save Manager allow you to save the game separately from the main 4 save slots if you need more
